# Executive Summary

## Recommendation

FlowFinance should enter embedded finance through a **credit-readiness and cashflow-health analytics wedge**, not by becoming a lender. The best first market is digitally active MSMEs that already produce transaction data but lack lender-ready financial visibility.

## Why This Wedge

- FlowFinance already processes transaction categorization and health-score workflows.
- MSMEs need budgeting, cashflow visibility, and credit-readiness support before loan origination.
- Lenders and accountants can become distribution partners once consented transaction histories are structured.
- The analytics wedge avoids balance-sheet risk, regulatory burden, and collection complexity.

## Market Sizing

| Layer | Logic | Estimate |
|---|---|---:|
| TAM | 63M MSMEs x 35% digitally reachable x Rs 3,600 annual WTP | Rs 79B |
| SAM | 63M MSMEs x 18% serviceable x Rs 7,200 blended ARPA | Rs 82B |
| SOM Year 1 | 2,500 customers x blended ARPA | Rs 18M |
| SOM Year 3 | 50,000 customers x blended ARPA | Rs 360M |

## Unit Economics

The Pro tier is the best initial wedge: Rs 799/month, estimated 82% gross margin, Rs 1,400 CAC, 22-month expected life, Rs 14,414 LTV, and 2.14-month CAC payback. Partner API has larger LTV but requires a longer enterprise sales cycle.

## 12-Month Plan

1. Months 0-2: Package cashflow-health score, transaction taxonomy, and budget alerts into Pro tier.
2. Months 3-5: Acquire through accountants, CA firms, MSME consultants, and existing fintech customers.
3. Months 6-8: Add lender-readiness exports and portfolio dashboards for partner pilots.
4. Months 9-12: Convert highest-quality partner pilots into API distribution channels.

## Risks

- Low willingness-to-pay among micro merchants
- Data quality and transaction categorization errors
- Regulatory sensitivity if positioned as credit decisioning
- Enterprise partner sales cycle delays

## Decision

Proceed with analytics-first GTM. Do not enter direct lending. Build lender partnerships only after the product has repeatable data quality, retention, and consented export workflows.
